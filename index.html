Onion Viewer

Gib eine .onion-Adresse ein und öffne sie im Tor Browser oder über ein Gateway.

Im Tor Browser öffnest du die Seite direkt und anonym. Gateways leiten die Anfrage über einen fremden Server, der mitlesen kann.

Vorschau

Bleibt das Fenster leer, verbietet die Seite oder das Gateway das Einbetten. Nutze dann „Über Gateway öffnen“.

Lesezeichen

    Noch keine Lesezeichen. Gib oben eine Adresse ein und wähle „Speichern“.

    Gateways

    Gateway-Liste bearbeiten

    Eine Vorlage pro Zeile. {name} steht für die Adresse ohne „.onion“. Gateways fallen oft aus, dann trägst du hier ein anderes ein.

    Alle Daten bleiben in deinem Browser (localStorage). Diese Seite sendet nichts an einen eigenen Server.
